# Tico e Lila — A semente apressada
Desenho infantil original, 60 segundos exatos, vertical 1080×1920, 24 fps. Tico é um pequeno dinossauro verde-água com lenço laranja; Lila é uma coelha lilás com jardineira azul. História sobre cuidado e paciência, com passagem explícita dos dias.

Vozes solicitadas: Cadu (Piper pt_BR-cadu-medium), Francisca (Edge pt-BR-FranciscaNeural). Sem substituição de vozes e sem Kokoro. Falas devem caber nas cenas sem cortes. Trilha instrumental original gerada por código.

Recursos reutilizados: Remotion para vídeo e animação vetorial articulada; Motion Canvas core para curvas de movimento; Rhubarb para boca sincronizada; faster-whisper para tempos; texto autoral preservado; MoviePy para áudio. Neste desenho 2D os personagens e cenários são SVG originais animados, sem usar fundos Blender ou bonecos Pablo Guru.

Branch separada, sem publicação em redes sociais. Workflow executa somente quando esta área é alterada na branch de laboratório. Arquivo final e relatório ficam em results/.
