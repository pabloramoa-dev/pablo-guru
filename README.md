# Pablo Guru

Laboratório e futura linha de produção dos vídeos do **Pablo Guru**.

Este repositório é independente dos projetos de previsão do tempo. Os repositórios existentes servem apenas como referência técnica de Manim, personagens, áudio, lip-sync, câmera e renderização.

## Objetivo

Construir um personagem 2D modular e moderno, com qualidade visual superior aos personagens anteriores, preservando automação local:

`roteiro -> vozes -> lip-sync -> rig 2D -> cena Manim -> FFmpeg -> MP4 9:16`

## Princípios

- sempre dois personagens em cada episódio: **Perguntador** e **Pablo Guru**;
- o nome **Pablo Guru** é sempre usado no diálogo;
- personagem modular, com partes independentes para expressão e gestos;
- microanimações contínuas: respiração, piscadas, olhar e postura;
- cenários em camadas, câmera suave, profundidade e elementos atmosféricos;
- execução local no notebook como destino final;
- o projeto não publica no Instagram nesta fase de laboratório.

## Estado

Fase inicial de P&D visual e técnico.
